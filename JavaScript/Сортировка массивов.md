По умолчанию `sort()` сортирует всё как строки (из-за чего `10` может встать _перед_ `2`), поэтому для чисел мы всегда передаем функцию-компрессор (колбэк): `sort((a, b) => ... )`.

---

## Главное правило, которое нужно запомнить:

Движок JS смотрит на знак результата (числа), которое возвращает твоя функция:

- Если результат отрицательный (`< 0`) — `a` ставится перед `b`.
- Если результат положительный (`> 0`) — `a` ставится после `b`.
- Если результат ноль (`0`) — порядок не меняется.

---

## Шпаргалка: Как запомнить формулу

В колбэк всегда приходят два элемента: `a` (текущий) и `b` (следующий).

## 1. По возрастанию (от меньшего к большему): `a - b`

Представь, что в массиве идут числа `5` и `10`. Значит, `a = 5`, `b = 10`.

- Подставляем в формулу `a - b`: получаем `5 - 10 = -5`.
- Результат отрицательный, значит `a` (5) ставится перед `b` (10).
- Числа встали как надо: сначала меньшее, потом большее.

> Ассоциация для запоминания: Алфавитный порядок. Буква `a` идет первой в алфавите, буква `b` — второй. Возрастание — это естественный порядок. Значит, пишем `a - b`.

```javascript
const numbers =;
numbers.sort((a, b) => a - b);
console.log(numbers); // [1, 2, 4, 5]
```

## 2. По убыванию (от большего к меньшему): `b - a`

Снова берем `a = 5`, `b = 10`. Мы хотим, чтобы большее число (10) встало впереди.

- Подставляем в вывернутую формулу `b - a`: получаем `10 - 5 = 5`.
- Результат положительный, значит `a` (5) улетает назад, уступая место для `b` (10).
- Сначала идет 10, потом 5. Порядок убывания соблюден.

> Ассоциация для запоминания: Убывание — это «перевернутый», неестественный порядок. Значит, мы переворачиваем буквы местами и пишем `b - a`.

```javascript
const numbers =;
numbers.sort((a, b) => b - a);
console.log(numbers); // [5, 4, 2, 1]
```

---

## ⚠️ Важное предупреждение (Мутация)

Помни, что метод `.sort()` мутирует (изменяет) исходный массив, а не создает новый.

Если на собеседовании или в проекте тебе нужно отсортировать массив, не испортив оригинал, сначала сделай его копию через спред-оператор `[...array].sort(...)` или используй современный метод `array.toSorted()`, который сразу возвращает новый отсортированный массив, оставляя старый нетронутым.
