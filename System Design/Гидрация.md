**Что такое Гидрация (Hydration)?**

Представь, что ты заходишь на сайт, который использует **SSR** (Server-Side Rendering — рендеринг на сервере).

1. **На сервере:** Движок (например, Node.js) берет твой React/Vue компонент, превращает его в обычный плоский текст (HTML-код) и мгновенно отправляет в браузер.
2. **В браузере (Первое мгновение):** Пользователь сразу видит красивую готовую страницу с текстом и картинками. Но если он попробует кликнуть на кнопку «Купить» или открыть бургер-меню, **ничего не произойдет**. Страница пока представляет собой просто «слепок» или сухую картинку. Она не интерактивна, потому что код на JavaScript еще не загрузился и не привязался к кнопкам.
3. **Процесс гидрации:** Браузер докачивает JS-файл фреймворка. Фреймворк пробегается по уже существующему HTML-дереву, находит нужные кнопки, вешает на них обработчики событий `addEventListener` создает внутреннее виртуальное дерево (Virtual DOM).

**Главный минус полной гидрации:** Пока скачивается и выполняется весь огромный JS-пакет для страницы, процессор пользователя заблокирован (метрика **TTI — Time to Interactive** страдает) [🔎]. Страницу уже видно, но потыкать в неё еще нельзя.

**Что такое Частичная гидрация (Partial Hydration)?**

Чтобы пользователь не ждал, пока «оживет» весь огромный сайт, инженеры придумали **частичную гидрацию** (она лежит в основе **архитектуры островов / Islands Architecture**, популяризированной фреймворком **Astro**).

Суть идеи: Зачем скачивать JavaScript и «гидрировать» те части сайта, которые вообще никогда не изменятся и не требуют кликов (например, шапка сайта, футер, статическая статья, боковое меню с текстом)?

При частичной гидрации:

- Сервер отдает HTML всей страницы целиком.
- Браузер скачивает JavaScript **только для тех маленьких кусочков (островков), которые реально интерактивны** (например, только для виджета корзины или формы обратной связи) [🔎].
- Только эти «островки» проходят процесс гидрации и оживают. Всё остальное тело сайта остается чистым, легковесным HTML, который не нагружает процессор.
