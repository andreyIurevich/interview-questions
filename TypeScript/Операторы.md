`typeof`

Принимает объект, переменную или функцию из JS-кода и генерирует её точный TS-тип.
Выступает мостиком между миром JS и миром типов. Работает только при компиляции.

`keyof`

Этот оператор работает **строго с типами**. Он принимает тип объекта и возвращает строку-литерал или число-литерал для каждого ключа, объединяя их через `|` (Union).

```js
const ROLES = {
  admin: "ADMINISTRATOR",
  editor: "EDITOR",
  viewer: "VIEWER"
} as const; // as const делает свойства readonly и сохраняет точные значения-литералы

// 1. Сначала typeof превращает объект ROLES в тип
// 2. Затем keyof забирает ключи этого типа
type RoleSymbols = keyof typeof ROLES;

// Результат: "admin" | "editor" | "viewer"
```

**Пересечение типов (Intersection Types)** обозначается оператором **`&`** (амперсанд). Если объединение (`|`) работает как логическое «ИЛИ», то пересечение (`&`) работает как логическое **«И»**.

Оно берет несколько существующих типов и **склеивает их в один новый тип**, который содержит абсолютно все свойства каждого из исходных типов.

```ts
type User = {
  id: string;
  name: string;
  email: string;
};

// Добавляем к типу User временные метки
type Timestamps = {
  createdAt: Date;
  updatedAt: Date;
};

// Создаем итоговый тип для базы данных
type DbUser = User & Timestamps;

const userInDb: DbUser = {
  id: "usr_123",
  name: "Alex",
  email: "alex@example.com",
  createdAt: new Date(),
  updatedAt: new Date(),
};
```
