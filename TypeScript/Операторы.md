`typeof`

Принимает объект, переменную или функцию из JS-кода и генерирует её точный TS-тип.
Выступает мостиком между миром JS и миром типов. Работает только при компиляции.

`keyof`

Этот оператор работает **строго с типами**. Он принимает тип объекта и возвращает строку-литерал или число-литерал для каждого ключа, объединяя их через `|` (Union).

```js
const ROLES = {
  admin: "ADMINISTRATOR",
  editor: "EDITOR",
  viewer: "VIEWER"
} as const; // as const делает свойства readonly и сохраняет точные значения-литералы

// 1. Сначала typeof превращает объект ROLES в тип
// 2. Затем keyof забирает ключи этого типа
type RoleSymbols = keyof typeof ROLES;

// Результат: "admin" | "editor" | "viewer"
```
