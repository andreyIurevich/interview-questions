Пишем свою мини-лабораторию:

```typescript
type Expect<T extends true> = T;

type Equal<X, Y> =
	(<T>() => T extends X ? 1 : 2) extends
	(<T>() => T extends Y ? 1 : 2) ? true : false;

type Invert<T extends Record<string, string>> = {
	[K in keyof T as T[K] & string]: K
};

type MyCompanyType = {
	admin: 'Администратор',
	stuff: 'Администратор'
};

type Expected = { "Администратор": "admin" | "stuff" };

type Test1 = Expect<Equal<Invert<MyCompanyType>, Expected>>;
```

**Готовые библиотеки для тестирования типов (Для продакшена)**

Если ты пишешь большую библиотеку или хочешь добавить тесты типов в общую систему тестирования (Jest / Vitest), использовать кастомные костыли неудобно. Для этого есть профессиональные инструменты.

1. Библиотека `type-fest` (Набор готовых типов)

В ней уже есть готовый тип `IsEqual<A, B>`, аналогичный тому, что выше.

2. Библиотека `tst-query` или встроенный инструмент в Vitest (`expectTypeOf`)

Если ты используешь современный тестовый фреймворк **Vitest**, в него уже «из коробки» встроен крутейший инструмент для проверки типов. Ты пишешь обычные файлы `.test.ts`, и они проверяются при запуске тестов:

```ts
import { expectTypeOf, test } from 'vitest';

test('тестируем утилиту Invert', () => {
  type MyResult = Invert<{ admin: "Администратор" }>;
  
  // Проверяет строгое соответствие типов на этапе компиляции:
  expectTypeOf<MyResult>().toEqualTypeOf<{ "Администратор": "admin" }>();
});
```
