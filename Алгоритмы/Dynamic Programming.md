Максимальная сумма подмассива (Maximum Subarray / Алгоритм Кадана)

Мы идем по массиву слева направо и в каждый момент времени (на каждом элементе) принимаем ровно одно ключевое решение:

> **Что выгоднее:** прибавить текущее число к уже существующему накопленному подмассиву ИЛИ отбросить старый подмассив и начать новый прямо с текущего числа?

Старый подмассив выгодно отбросить в одном единственном случае: если сумма, которую мы накопили до этого, стала **отрицательной**. Отрицательная сумма только уменьшит результат для любого последующего элемента.

```js
function maxSubArrayWithIndices(nums) {
  let currentSum = nums[0];
  let maxSum = nums[0];
  
  let start = 0;     // Потенциальное начало нового подмассива
  let leftP = 0;     // Финальное начало
  let rightP = 0;    // Финальный конец

  for (let i = 1; i < nums.length; i++) {
    // Если выгоднее начать заново, сдвигаем временный старт на текущий индекс
    if (nums[i] > currentSum + nums[i]) {
      currentSum = nums[i];
      start = i;
    } else {
      currentSum += nums[i];
    }

    // Обновляем глобальный максимум и фиксируем границы
    if (currentSum > maxSum) {
      maxSum = currentSum;
      leftP = start;
      rightP = i;
    }
  }

  // Для проверки выведем сам подмассив
  console.log("Подмассив:", nums.slice(leftP, rightP + 1));
  return maxSum;
}
```
