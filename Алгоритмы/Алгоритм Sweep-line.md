«Пиковая загрузка аэропорта» (Maximum Airplanes in the Sky)

**Условие:**  
Вам дан массив расписания рейсов крупного авиахаба. Каждый элемент массива представляет собой объект или массив с временем прилёта (landing) и временем вылета (takeoff) самолёта: `[[landing_1, takeoff_1], [landing_2, takeoff_2], ...]`.

Самолёт занимает место на перроне (стояночном месте) аэропорта с момента прилёта до момента вылета. Если один самолёт вылетает ровно в то же время, когда другой прилетает (например, в `12:00`), то считается, что стояночное место успевает освободиться (конфликта нет).

**Задача:**  
Найдите **минимальное количество стояночных мест (гейтов)**, которое должен иметь аэропорт, чтобы гарантированно обслужить все рейсы без задержек.

**Пример входных данных:**

```js
const flights = [
  ["10:00", "14:00"],
  ["11:00", "12:00"],
  ["12:00", "13:00"],
  ["13:30", "15:00"]
];
```

Разбор сути решения через Sweep-line Algorithm

Давай применим наш метод сканирующей прямой. Переведём время в удобные минуты с начала суток (чтобы легче сортировать), разобьём интервалы на события и пустим наш «лазерный луч» по шкале времени.

1. **Дробим на события:**
    - Прилёт (Landing) ➡️ событие **`+1`** (самолёт сел, занял гейт).
    - Вылет (Takeoff) ➡️ событие **`-1`** (самолёт улетел, освободил гейт).
2. **Формируем массив событий:**
    - Из `["10:00", "14:00"]` получаем: `[600, 1]` и `[840, -1]` (10 часов = 600 минут, 14 часов = 840 минут).
    - Проделываем это со всеми рейсами.
3. **Сортируем:**  
    Поскольку по условию задачи в `12:00` один самолёт улетает, а второй садится, и они _не конфликтуют_, мы используем ту же самую магию сортировки, которую ты написал для комнат. Мы ставим **вылет (`-1`) перед прилётом (`1`)**, если время совпало.
    
4. **Считаем пиковую нагрузку:**  
    Бежим по массиву событий:
    - Время 10:00 (Прилёт) ➡️ `count = 1`, `maxGates = 1`
    - Время 11:00 (Прилёт) ➡️ `count = 2`, `maxGates = 2`
    - Время 12:00 (Вылет 2-го рейса) ➡️ `count = 1` (гейт освободился)
    - Время 12:00 (Прилёт 3-го рейса) ➡️ `count = 2`, `maxGates = 2`
    - Время 13:00 (Вылет 3-го рейса) ➡️ `count = 1`
    - Время 13:30 (Прилёт 4-го рейса) ➡️ `count = 2`, `maxGates = 2`
    - Время 14:00 (Вылет 1-го рейса) ➡️ `count = 1`
    - Время 15:00 (Вылет 4-го рейса) ➡️ `count = 0`

Максимальное одновременно нужное количество гейтов (`maxGates`) за все сутки составило **2**. Аэропорту достаточно иметь всего 2 стояночных места, чтобы принять все эти самолёты.
